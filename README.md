# tyloo.fr

Portfolio of Julien Bonvarlet, senior freelance developer in Paris. French at `/fr`, English at `/en`.

Built with Next.js 16 (App Router, Cache Components), React 19, Tailwind CSS 4 and Biome.

## Develop

```sh
pnpm install
pnpm dev
```

## Check

```sh
pnpm lint
pnpm type-check
pnpm build
```

## For AI agents

The site publishes [`/llms.txt`](https://tyloo.fr/llms.txt) and a Markdown version of each page (`/fr/index.md`, `/en/index.md`), plus JSON-LD structured data.
